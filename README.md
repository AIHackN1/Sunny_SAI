# Sunny SAI · 차량용 웨비게이션

**처음 설정하는 분: [키 입력 위치·Vercel 배포 안내](SETUP.md)** — 실제 키는 GitHub Settings의 Secrets에 등록합니다.
목적지까지 지날 구간의 예상 통과시각에 기상정보를 연결하고, 필요한 순간에 짧게 안내하는 차량용 음성 동승자입니다. 보행 지원은 후속 범위입니다.

## 바로 체험

앱에서 **진천 → 서울 시연하기 → 시연 재생**을 선택합니다. 비·돌풍·가상 공사 안내, 진행 슬라이더, 일시정지, 다시 듣기, 음성 중단을 사용할 수 있습니다. 시연의 경로·소요시간·기상·공사는 모두 가상이며 실제 운전에 사용하지 않습니다.

실제 모드: 출발지·목적지 검색 및 선택 → 차량 경로 조회 → 도로별 누적 예상 소요시간에서 표본 구간 ETA 계산 → Open-Meteo 시간별 모델 예보 조회 → 출처·예보 유효시각·조회시각·결측 표시. 모델 예보를 실제 도로 위험도나 공식 기상특보로 표현하지 않습니다.

## 개발

Node.js 24.11 이상(24.x)과 pnpm 11.25.0을 권장합니다. 저장소의 lockfile에 맞춰 설치합니다.

```bash
corepack enable
pnpm install --frozen-lockfile
cp .env.example .dev.vars
# .dev.vars에 개발용 값 입력
pnpm dev
```

개발 환경의 실제 주소와 APP_ORIGIN을 정확히 맞춥니다. 로컬은 http://localhost:5173, 외부 배포는 HTTPS를 사용합니다. Work 관리 환경의 preview는 지정 supervisor를 사용합니다.

```bash
pnpm check
pnpm test
pnpm build
```

배포: `.openai/hosting.json`은 기존 Sites 프로젝트를 가리킵니다. 새 프로젝트를 중복 생성하지 않습니다. 자체 Cloudflare 배포는 조직의 Wrangler 설정·비밀값·접근제어를 별도로 준비해야 합니다.

## 운영자 설정

`.env.example`에는 이름만 있습니다. 서비스 설정 화면에서 아래 환경변수를 지정합니다.

- `APP_ORIGIN`: HTTPS 배포 origin, 끝의 `/` 없이 지정.
- `SESSION_SECRET`: 최소 43자 이상의 암호학적 무작위 비밀값. 사용자 Google 키와 별도 관리. 변경 시 모든 기존 세션/음성키 무효화.
- `KAKAO_REST_API_KEY`: 서버 전용. Local 검색 및 Mobility 길찾기 사용 권한과 할당량 확인.
- `KAKAO_JAVASCRIPT_KEY`: 브라우저 지도용. 허용 웹 도메인 등록. 브라우저 키는 클라이언트에 표시되는 값입니다.
- `VWORLD_API_KEY`: 위성 배경지도용, 도메인·사용조건 제한 적용. GK2A 기상영상 키와 다릅니다.

Google 키는 운영자 공용 환경변수로 넣지 않고 사용자가 앱 **설정 → 고급 음성**에서 선택적으로 연결합니다. 키 발급을 기본 사용자 이용 조건으로 요구하지 않습니다. TTS API 활성화, API 제한, 할당량, 결제 설정은 사용자 계정에서 관리합니다.

## 보안·위치 데이터

사용자 Google 키는 AES-256-GCM(96비트 무작위 nonce, 목적·세션·방문자 바인딩)으로 암호화한 HttpOnly·Secure·SameSite=Strict 쿠키에 최대 30분 보관합니다. 서버 비밀값은 소스·브라우저 번들에 포함하지 않습니다. 영구 저장·KMS 봉투 암호화는 구현 범위가 아닙니다. 삭제 시 현재 브라우저 쿠키를 만료하며, 탈취된 쿠키의 즉시 서버 철회 기능은 없고 최대 세션 만료까지 유효할 수 있습니다.

Origin·CSRF 검사, 입력 크기 제한, 서버별 세션 호출 제한, 사용자/세션 간 키 접근 차단, 공급자 오류 내용 비노출을 적용했습니다. 메모리 기반 호출 제한은 다중 Worker 전체를 아우르는 과금 한도를 보장하지 않습니다. 공개 운영 전에는 플랫폼 WAF/지속형 제한과 사용량 정책을 추가해야 합니다. Sites의 기존 인증·비공개 접근 경계는 유지합니다.

마이크는 버튼을 누를 때만 활성화합니다. 브라우저 음성 인식은 브라우저 공급자 서버를 사용할 수 있습니다. 경로·예보 조회 시 입력 위치·목적지는 Kakao/Open-Meteo에 전달됩니다. 애플리케이션은 이동 이력을 영구 저장하지 않습니다. 브이월드 사용 시 타일 요청 정보는 공급자에게 전달됩니다. API 및 사용자키는 서비스워커 캐시에 저장하지 않습니다.

웹/PWA는 화면 닫힘·잠금 상태에서 연속 위치 추적이나 음성 동작을 보장하지 않습니다. 현재 실제 경로의 자동 GPS 주행 감시는 제공하지 않으며 시연 모드에서 조건부 알림을 검증합니다. 앱스토어 게시·APK/IPA는 후속입니다.
