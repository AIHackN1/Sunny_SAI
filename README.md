# Sunny SAI · 맑은날

어르신·보행약자를 위한 음성 이동 지원 웹앱의 첫 개발 버전입니다. TePilot의 공개된 상황별 음성 안내 흐름을 참고하여 독립 구현했습니다. TePilot의 코드·이미지·브랜드를 복제하지 않았습니다.

## 실행

Node.js 22 이상, 외부 npm 의존성 없음.

```sh
npm test
npm run check
node --env-file=.env server.mjs
```

먼저 `.env.example`을 `.env`로 복사합니다. 기본 주소는 `http://localhost:3000`입니다. 지도 키 없이도 화면과 브라우저 음성을 사용할 수 있습니다. 키는 코드·이슈·PR·스크린샷에 넣지 마세요.

## 현재 기능

- 큰 버튼·확대 가능한 글씨, 목적지 텍스트 입력
- 지원 브라우저의 한국어 음성 입력과 기기 음성 재생·중단·다시 듣기
- 운영자 Kakao JavaScript 키 설정 시 실제 지도·장소 검색·장소 선택
- 운영자 VWorld 키 설정 시 Leaflet 기반 위성 배경지도 전환
- 동의 후 위치 확인, 선택한 장소를 카카오맵 길찾기로 열기
- 선택형 Google Cloud TTS: 서버 세션에만 키를 임시 암호화 보관
- 홈 화면 추가용 manifest. 서비스워커·오프라인 기능·앱스토어 패키지는 아직 없음

## 구현하지 않은 기능

기상자료·보행 경로 계산·계단/경사 정보·쉼터 데이터·침수 예측·LLM 대화·앱 백그라운드 추적은 연결되지 않았습니다. 음성 목적지 처리는 규칙 기반이며 생성형 AI가 아닙니다. GK2A 지표면온도를 기온·도로 표면온도로 표시하지 않습니다. 안전 경로나 대피 경로를 보장하지 않습니다.

## 지도 설정

`KAKAO_JAVASCRIPT_KEY`와 `VWORLD_API_KEY`는 각각 서비스 운영자 키입니다. 지도 SDK/타일 요청에 필요한 브라우저용 키이므로 사용자 브라우저에서 보입니다. 각 제공자에서 배포 도메인과 사용 API 제한을 설정하세요. 이를 비밀키 은닉 또는 도용 완전 차단이라고 주장하지 않습니다. Kakao REST/Admin 키는 브라우저 설정에 사용하지 마세요.

초기 지도 중심은 진천입니다. 검색 결과 위치로 이동할 수 있습니다. 브이월드는 배경지도이며 보행 경로 엔진이 아닙니다. 지도 키·도메인 승인 및 실제 브라우저 검증 전에는 연동 완료로 간주하지 마세요.

## 배포

장시간 실행 가능한 단일 Node.js 서버가 필요합니다. `.env`는 로컬 개발용이며 운영에서는 호스팅 비밀 설정을 사용합니다. 운영 `APP_ORIGIN`을 실제 HTTPS 원점으로 정확하게 설정하세요. 기본 `npm start`는 `.env`를 자동 로드하지 않습니다. 환경변수를 주입하거나 위 `--env-file` 명령을 쓰세요.

이 버전의 암호화 세션은 프로세스 메모리에 있으므로 여러 인스턴스·서버리스에 그대로 배포하면 세션이 끊깁니다. Vercel 정적 배포만으로 고급 음성은 동작하지 않습니다. 서버 재시작 시 모든 세션 키가 사라집니다. 앱스토어 배포는 별도 단계입니다.

## 고급 음성 보안

Google Cloud Text-to-Speech 전용 설정이며 Gemini 키 연결 기능이 아닙니다. 키 형식만 등록 시 확인하고 실제 접근은 음성 요청 시 확인합니다. 실패 시 기기 음성으로 전환합니다. 등록과 실제 호출은 사용자 의사에 따라 진행되며 이 저장소에는 실제 Google 키가 없습니다.

- 무작위 256비트 세션 쿠키, HttpOnly·SameSite=Strict, 운영 HTTPS에서 Secure
- Origin·CSRF 검사, 사용자 세션 격리, 입력 크기·문장 길이 제한, 세션별 호출 제한
- Google 키는 AES-256-GCM으로 서버 메모리에 암호화. 고유 IV·세션 ID AAD 적용
- 암호화 마스터키도 서버 메모리에만 존재. 디스크·DB·Git·localStorage에 키 저장 안 함
- 최대 30분 세션, 명시적 삭제, 서버 재시작 시 소멸
- Google 호출은 키를 URL 대신 HTTP 헤더로 전달. 원본 오류와 키를 응답·로그로 출력하지 않음
- 안내 문장은 우리 서버와 Google에 전달됨. 사용자의 Cloud 프로젝트 과금·할당량·이용약관 적용

메모리 암호화는 실행 중 서버 침해를 막는 보장이 아닙니다. JS 문자열의 완전한 메모리 삭제도 보장하지 않습니다. 익명 세션 방식은 운영용 로그인 대체가 아니며 인터넷 공개 전 별도의 사용자 인증·전역 요청 제한·봇 방어가 필요합니다. 음성 입력은 브라우저 제공자 서버에서 처리될 수 있습니다. 항상 듣기 기능은 없습니다.

영구 저장을 추가할 때는 검증된 로그인, 사용자별 권한, KMS 봉투 암호화, 키 회전·삭제·감사·백업 정책, 세션 탈취 및 XSS 방어를 함께 구현해야 합니다. 영구 저장은 이 버전 범위에 없습니다.

## 검증

`npm test`는 암호화 보관·만료·삭제, 세션 간 격리, Origin/CSRF 거부, 문장 길이 제한, 호출 제한, 오류 비노출을 검증합니다. Google 호출은 mock 사용으로 실제 과금이 없습니다. 실제 지도·음성 인식·Google TTS·모바일 화면은 운영자 키와 실제 브라우저에서 후속 검증이 필요합니다.

## REA 활용

REA는 앱 의존성이 아닌 개발용 분석 도구입니다. 설치/분석 기록은 `docs/rea-workflow.md`에 설명합니다. 현재 버전은 업로드된 HTML 검토와 TePilot 공개 소개를 참고해 구현했으며 REA 실행 결과를 주장하지 않습니다.
