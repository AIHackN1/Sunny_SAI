    음성 설정

    기본 음성은 기기·브라우저의 음성 기능을 사용합니다.

    고급 음성 · Google Cloud 연결

    Google Cloud Text-to-Speech API 키가 있는 분만 선택해서 사용하세요. 일반 Google 계정 비밀번호나 Gemini 전용 키를 입력하지 마세요.

    서버 메모리에 AES-256-GCM으로 암호화해 최대 30분 임시 보관합니다. 키는 파일·DB·브라우저 저장소에 저장하지 않습니다. 서버가 재시작되면 사라집니다.

    연결 안 됨 · 기본 음성 사용

    연결 시 안내 문장이 우리 서버를 거쳐 Google로 전송되며, 사용자 Google 프로젝트에 비용이 발생할 수 있습니다. 키 형식 확인은 API 사용 가능 여부 검증과 다릅니다.
