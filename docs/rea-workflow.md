# REA 분석 적용 계획

공식 저장소: https://github.com/morluto/rea

개발 PC에서 공식 README가 요구하는 Node.js 버전을 확인하고 `npx rea-agents setup`을 실행합니다. Codex를 선택하고 설정 변경을 검토한 뒤 재시작합니다. 이 설치는 배포 앱이나 서버에 필요하지 않습니다.

분석 범위: 테파일럿의 공개 웹 안내와 합법적으로 접근할 수 있는 사용 흐름. 모바일 앱 내부 분석은 분석 가능한 앱 파일·테스트 환경·이용 권한이 확보됐을 때 별도로 진행합니다. 홈페이지 분석만으로 모바일 앱의 백그라운드 동작을 확인했다고 주장하지 않습니다.

질문: 필요한 순간의 음성 안내 시작/중단, 알림 중복 방지, 사용자의 확인 단계, 음성 실패 시 대체 UX.

분석 기록은 관찰한 사실·추정·제약으로 구분하고, 자체 코드로 재구현합니다. 현재는 REA가 이 작업 환경에 연결되거나 실행된 상태가 아닙니다.
