# 테파일럿 공개 화면에서 확인한 흐름

관찰일: 2026-10-21 (KST). 대상: https://tepilot.weekendproject.net/

공개 웹 페이지에 직접 접근해 한국어로 전환하고, 주행 보조·AI 음성·자동화·목적지 전송·설정 설명을 확인했습니다. 이 페이지는 소개 웹사이트입니다. 모바일 앱을 설치하거나 차량 BLE를 페어링하지 않았으며, 백그라운드 성능·실제 TTS 음질·주행 안전성을 체험한 기록이 아닙니다.

관찰한 기능 설명: WHEN/IF/THEN 자동화, 필요한 순간의 음성, 중복·동시 안내 처리, 확인 후 실행 옵션, 외부 내비에 목적지 전달. 실제 앱 내부 구현방식은 확인되지 않았습니다.

Sunny SAI에 적용한 자체 설계: 차량 경로→예상 통과시각→구간 기상자료→짧은 안내. 시연에서 10분 전 구간 접근과 조건을 확인하고 같은 이벤트 ID는 한 번만 안내합니다. 실제 경로 자동 감시는 아직 제공하지 않습니다. 브이월드는 위성 배경이며 GK2A 관측 대체물이 아닙니다.

테파일럿의 소스·아이콘·캐릭터·상표를 복제하지 않았습니다. 공개 기능 설명은 모티브이며 동일 기능·성능이나 제휴를 주장하지 않습니다.
